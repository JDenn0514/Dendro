# Leaf-only first version Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app teaches leaves only. The bark and fruit content stays in `content/` and stays valid, and the app does not show it. One constant in `app/main.js` turns bark and fruit back on later.

**Architecture:** `loadContent` in `app/logic/content.js` takes an optional list of active channels. It validates the full content first, then keeps only the active channels in the content object that the screens read. `app/main.js` passes `['leaf']`. The pipeline and the tests call `loadContent` with no list, so they keep every channel. The wrong-answer chooser in `app/logic/question.js` stops taking edge neighbours from other channels. Two screen links stop saying "three channels", and the home line drops its breakdown by channel when only one channel is active. The `content-run` skill tells agents to run `--channels leaf`.

**Tech Stack:** Plain HTML, CSS, and ES modules in `app/`, with no runtime dependency. Tests run with `node --test`. Node 24.

Source: the spec `docs/superpowers/specs/2026-09-30-leaf-only-v1-design.md` and the ruling `docs/decisions/2026-09-30-leaf-only-v1.md`.

Notes against the spec (the names were checked in the code on 2026-09-30):

- Every field name that the spec gives is correct: `channels`, `cards`, `cards_by_channel`, `unit_cards`, `concepts_by_channel`, `units`, and `confusion`. The line numbers are correct too.
- The content object has two more fields that the spec does not name: `concepts` (the full concept list) and `unit_members` (keyed by unit). This plan filters both, so that no field of the content object holds a hidden channel. `concepts` feeds `conceptFor`, the grader, and the reveal text. `unit_members` feeds the progress table.
- `species` and `manifest` stay whole. A species record keeps its `concepts.bark` key. The species page reads `content.channels` for its facts and plates, so it shows no bark or fruit with no change to `app/screens/species.js`.
- The screens have no tests. The app tests import logic modules only, because the screens need `document`. Task 3 has a manual check in place of a test.

## Choices made where the spec is silent

1. **The unknown-channel error uses the validator's error shape.** It is `{ file: 'concepts.json', message: 'no concept is on the active channel <name>' }`. `app/main.js` prints every error as `<file>: <message>` under "Content failed to validate", so this error shows the same way as a validator error.
2. **An empty list is an error too.** `{ channels: [] }` gives `{ file: 'concepts.json', message: 'the list of active channels is empty' }`. An app with no channel shows blank screens, so a loud error is the safe side. No list at all (`undefined`) keeps every channel.
3. **`loadContent` returns the validator's errors and the channel errors together.** A bad bark row and an unknown channel both show on the one error page.
4. **The active channels keep the order of `concepts.json`,** not the order of the list. The screens loop over `content.channels`, and that order stays the same as today.
5. **`content.warnings` stays the validator's full list.** A unit-size warning for `bark_types` still shows in the validator output. No screen prints the warnings.
6. **The home line with one channel stops at the count.** Today it reads `Five cards are due today: five leaf.` With one channel it reads `Five cards are due today.` With two or more channels it keeps the breakdown.
7. **The back links name the page they open.** `concept.js` says `Back to Progress`. `lessons.js` says `Back to Lessons`. The words match the foot navigation and the trail, and they are true for any number of channels.
8. **`edgeNeighbours` loses its `sameChannelOnly` argument.** After Task 2 every caller wants the same channel only, so the argument has no use.
9. **The fold state of a hidden channel can drop out of settings.** `mergeOpenUnits` (`app/logic/lessons.js:127-135`) drops a stored unit key whose unit is not in `content.units`. After this change a fold on a leaf channel page drops the stored bark and fruit fold keys from `settings.open_units`. This is a view setting, not card progress. When bark comes back, its units show folded or unfolded by the default rule. The card states in `dendro_cards` stay. No code in the app deletes a card state for a card that is not in the content. This plan does not change `mergeOpenUnits`.

```js
// The errors for a list of active channels. No list means every channel.
function activeChannelErrors(allChannels, active) {
  if (active === undefined) return [];
  if (active.length === 0) {
    return [{ file: 'concepts.json', message: 'the list of active channels is empty' }];
  }
  return active
    .filter((name) => !allChannels.includes(name))
    .map((name) => ({
      file: 'concepts.json',
      message: `no concept is on the active channel ${name}`
    }));
}

// Validates the full content, then keeps only the active channels in the object
// the screens read. A bad row on a hidden channel still fails. The species
// records and the manifest stay whole, so a hidden channel comes back with no
// content change.
export function loadContent(raw, { channels: active } = {}) {
  const { errors, warnings } = validateContent(raw);
  const allChannels = deriveChannels(raw.concepts);
  const failures = [...errors, ...activeChannelErrors(allChannels, active)];
  if (failures.length > 0) return { ok: false, content: null, errors: failures, warnings };

  const channels = active === undefined
    ? allChannels
    : allChannels.filter((channel) => active.includes(channel));
  const onActiveChannel = (item) => channels.includes(item.channel);
  const concepts = raw.concepts.filter(onActiveChannel);
  const units = raw.units.filter(onActiveChannel);
  const confusion = raw.confusion.filter(onActiveChannel);

  const cards = deriveCards(raw, channels);
  const cardsByChannel = {};
  for (const channel of channels) {
    cardsByChannel[channel] = Object.values(cards)
      .filter((c) => c.channel === channel)
      .map((c) => c.id);
  }
  const conceptsByChannel = {};
  for (const channel of channels) {
    conceptsByChannel[channel] = concepts.filter((c) => c.channel === channel);
  }
  const unitMembersByKey = {};
  const unitCardsByKey = {};
  for (const unit of units) {
    unitMembersByKey[unit.key] = unitMembers(raw, unit);
    unitCardsByKey[unit.key] = unitCards(unit, cards, raw);
  }

  const content = {
    species: raw.species,
    concepts,
    confusion,
    units,
    manifest: raw.manifest,
    channels,
    concepts_by_channel: conceptsByChannel,
    cards,
    cards_by_channel: cardsByChannel,
    unit_members: unitMembersByKey,
    unit_cards: unitCardsByKey,
    warnings
  };
  return { ok: true, content, errors: [], warnings };
}
```

// An edge on another channel says nothing about how two species differ on this
// one, so it gives no wrong answer here.
function edgeNeighbours(content, symbol, channel) {
  const out = [];
  for (const edge of content.confusion) {
    if (edge.channel !== channel) continue;
    if (edge.a === symbol) out.push(edge.b);
    if (edge.b === symbol) out.push(edge.a);
  }
  return out;
}

function stateSentence(content, states, today) {
  const total = dueCardIds({ content, states, focus: 'all', today }).length;
  const line = el('p', 'state1');
  if (total === 0) {
    line.append(el('b', null, 'No card'));
    line.append(document.createTextNode(' is due today.'));
    return line;
  }
  const verb = total === 1 ? 'is' : 'are';
  line.append(el('b', null, `${capitalize(numberWord(total))} ${total === 1 ? 'card' : 'cards'}`));
  // With one channel, the breakdown repeats the total, so the line stops here.
  if (content.channels.length === 1) {
    line.append(document.createTextNode(` ${verb} due today.`));
    return line;
  }
  const parts = content.channels
    .map((channel) => ({
      channel,
      count: dueCardIds({ content, states, focus: channel, today }).length
    }))
    .filter((part) => part.count > 0)
    .map((part) => `${numberWord(part.count)} ${channelLabel(part.channel)}`);
  line.append(document.createTextNode(` ${verb} due today: ${parts.join(', ')}.`));
  return line;
}
